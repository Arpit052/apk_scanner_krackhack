Getting Started

Upload your APK file using the Scanner tab. The tool supports APK files up to 300MB in size. Once uploaded, click "Start Security Scan" to begin the comprehensive analysis.

Understanding Results

Vulnerabilities are classified into four severity levels: Critical (immediate action required), High (urgent fixes needed), Medium (should be addressed), and Low (recommended improvements). Each vulnerability includes OWASP and CWE references for detailed understanding.

Learn more: OWASP Mobile Top 10

Exporting Reports

Export your scan results in multiple formats including JSON (for programmatic processing), HTML (for viewing in browsers), CSV (for spreadsheet analysis), and PDF (for sharing with stakeholders).

Best Practices

Regularly scan your APK files during development cycles. Address critical and high severity vulnerabilities immediately. Use the detailed remediation steps provided for each finding. Keep your development tools and libraries updated to minimize security risks.
